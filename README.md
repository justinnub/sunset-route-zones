# Sunset Valley Route Zones

Interactive ZIP code route-zone map for Sunset Wholesale West (Phoenix metro).

- `index.html`, `style.css`, `app.js`, `shell.js`: the page
- `data.js`: ZIP boundaries (US Census 2010 ZCTAs) and freeway reference lines (Natural Earth)
- `stores.js`: independent smoke shops, convenience stores and liquor stores (© OpenStreetMap contributors, ODbL)
